البحث والاستبدال: مطابقة حالة الأحرف والكلمة كاملة

اضغط Ctrl+F للبحث أو Ctrl+H للبحث والاستبدال. تفتح اللوحة فوق المحرر: خانة البحث، الاستبدال به، وخيارات مطابقة حالة الأحرف، الكلمة كاملة، Regex، والتفاف البحث.

الحركة بين النتائج

  • Enter في خانة البحث = النتيجة التالية.
  • Shift+Enter = النتيجة السابقة.
  • F3 = بحث/التالي، وShift+F3 = السابق.
  • Esc = إغلاق لوحة البحث والعودة للمحرر.

مثال عملي: cat concat Cat

لنفترض أن النص هو cat concat Cat وأردت استبدال كلمة cat فقط بكلمة dog:

  1. ابحث عن cat.
  2. أطفئ «مطابقة حالة الأحرف» (ليجد cat وCat).
  3. شغّل «كلمة كاملة».
  4. اضغط «استبدال الكل».

النتيجة: dog concat dog — لم تُستبدل cat داخل concat. أما بدون «كلمة كاملة» فستصبح dog condog dog.

خيار «كلمة كاملة» يعمل مع أي أبجدية: في العربية يجد «كتاب» وحدها دون «الكتاب» و«بكتاب»، ويدعم حدود الكلمات اليونيكودية بدقة.

مطابقة حالة الأحرف

عند تشغيلها يتميّز Cat عن cat؛ وعند إطفائها يُعاملان ككلمتين متطابقتين. للعربية لا يوجد فرق عملي (لا توجد حالة أحرف في العربية).

التعابير النمطية (Regex)

شغّل «Regex» لكتابة نمط متقدم، مثل:

  • \d+ — كل الأرقام المتتالية.
  • \s{2,} — مسافتان أو أكثر.
  • ^سطر — الأسطر التي تبدأ بكلمة «سطر».
  • ([أ-ي]+)@ — مجموعات قبل علامة @ (مثال تقريبي).

ملاحظة: عند تفعيل Regex يتم تجاهل خيار «كلمة كاملة» (يمكنك كتابة الحدود داخل النمط نفسه).

استبدال الكل والتراجع

«استبدال الكل» يستبدل كل النتائج دفعة واحدة، وCtrl+Z يتراجع عن العملية كاملة بضغطة واحدة.
