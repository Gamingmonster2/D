How to open Arabic (ANSI/Windows-1256) and UTF-16 .txt files online

If an Arabic text file shows up as Latin gibberish such as «ãÑÍÈÇ», the file was probably saved in an old ANSI encoding and opened as UTF-8 (or the other way around). You can read and fix it entirely in the browser with Notepad.

Step by step

  1. Open Notepad and click Open (or drag the file into the window).
  2. The app guesses the encoding: BOM first, then strict UTF-8, then UTF-16 patterns, then ANSI (Windows-1256).
  3. If the text is still garbled, change the Encoding selector in the status bar — try ANSI (Windows-1256), UTF-16 LE or UTF-16 BE.
  4. Once the text looks correct, click Save as and choose UTF-8 — the modern, universal choice.

Line endings (CRLF vs LF)

Windows files usually end lines with CRLF (0D 0A), while Unix/macOS and the web use LF (0A). Notepad detects the style on open and lets you choose it before saving, so scripts and config files keep working on the target system.

Why the browser is safe for this

The file is read locally by your browser and never uploaded. Saved files are written to your device, and unsaved work is autosaved in your browser storage with a restore bar after a reload.
