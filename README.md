# المفكرة — نسخة الويب (do.com.ly)

تطبيق مفكرة عربي يعمل على المتصفح (SPA) بلا خادم خلفي، مبني بعد **تحليل أداة `Notepad.exe` في ويندوز** باستخدام **REA + Ghidra** (انظر قسم «من أين جاء التصميم»).

- **الموقع:** <https://do.com.ly/> — النسخة الحالية تعمل على <https://www.do.com.ly/> و<https://d-a7a.pages.dev/>
- نشر تلقائي: كل `git push` إلى فرع `main` يُنشر عبر **Cloudflare Pages**.
- لا خادم ولا قاعدة بيانات: كل البيانات تبقى في متصفحك (IndexedDB + localStorage). لا تتبّع من طرف التطبيق؛ ملاحظة: إن كان **Cloudflare Web Analytics** مفعّلاً في حسابك فإن Cloudflare يحقن سكربت إحصاءات بلا كوكيز (يمكن تعطيله من لوحة Cloudflare، وسياسة CSP لدينا تسمح به صراحةً فقط لهذا النطاق).

## الميزات

- **ملفات:** جديد (Ctrl+N)، فتح (Ctrl+O)، حفظ (Ctrl+S)، حفظ باسم (Ctrl+Shift+S)، سحب وإفلات الملفات.
- **ترميزات:** UTF-8، UTF-8 مع BOM، UTF-16 LE، UTF-16 BE، ANSI (Windows-1256 العربية)، ANSI (Windows-1252).
- **كشف تلقائي** للترميز (BOM + UTF-8 صارم + استدلال UTF-16 + بديل ANSI) ونهاية السطر (CRLF/LF/CR).
- **بحث/استبدال:** التالي/السابق، التفاف البحث، حالة الأحرف، **Regex**، استبدال الكل.
- **عنوان المستند:** إعادة التسمية بالنقر على العنوان أو زر «تسمية» أو `F2`، ويُحفظ مع الحفظ التلقائي المحلي.
- **حفظ تلقائي محلي** للمستند الجاري + استعادة عند إعادة الفتح (IndexedDB).
- **العربية وRTL:** واجهة عربية كاملة، اتجاه تلقائي/يمين/يسار للنص، خطوط عربية (Naskh/Amiri/Tahoma…).
- **لغتان:** واجهة عربية RTL وإنجليزية LTR مع زر تبديل فوري أعلى الصفحة، ويُحفظ اختيار اللغة.
- **جوال وتثبيت:** تصميم متجاوب للهاتف وقابلية التثبيت كتطبيق ويب (PWA) على أندرويد وiOS وويندوز/ماك، مع زر تثبيت.
- إضافات حديثة: `.LOG` (إدراج التاريخ عند الفتح)، نقل إلى سطر (Ctrl+G)، إدراج التاريخ (F5)، وضع داكن، التفاف النص، طباعة، إحصائيات (سطر/عمود/حرف)، تسجيل Service Worker للعمل دون اتصال (PWA).

## التشغيل محلياً

```bash
# أي خادم ساكن، مثال:
npx serve .
# أو فتح index.html مباشرة (تفقد ميزات مثل اختيار ملفات النظام وPWA على file://)
```

ثم افتح `http://localhost:3000` (أو المنفذ الذي يظهر).

## الظهور في محركات البحث (SEO)

- بيانات وصفية بلغتين (title/description/keywords)، وروابط `canonical` وOpenGraph وTwitter.
- بيانات منظمة **JSON-LD** من نوع `WebApplication` تصف الأداة وميزاتها ولغاتها.
- صفحتا تعريف غنيتان بالمحتوى: `about.html` (عربي) و`about-en.html` (إنجليزي) مع `hreflang`.
- `sitemap.xml` و`robots.txt` للنطاق `do.com.ly`، وصورة مشاركة اجتماعية `assets/og-image.png`.
- أيقونات PWA كاملة (192/512/maskable/apple-touch) لتحسين الظهور والتثبيت.

## التخزين — كيف تُحفظ البيانات؟

التطبيق لا يرسل أي بيانات لأي خادم؛ كل شيء محلي في المتصفح:

| البيانات | مكان التخزين | ملاحظات |
|---|---|---|
| عنوان المستند + المستند غير المحفوظ (Autosave) | **IndexedDB** (`d-notepad` / `kv` / `autosave`) | يُحفظ تلقائياً أثناء الكتابة ويُعرض شريط «استعادة» عند إعادة الفتح |
| الإعدادات (الترميز، نهاية السطر، الخط، المظهر، الاتجاه) | **localStorage** (`d-notepad:settings`) | صغيرة وثابتة |
| الملفات النهائية | جهاز المستخدم عبر **File System Access API** أو تنزيل عادي | لا تبقى نسخة إضافية في الموقع |
| أصول التطبيق (للعمل دون اتصال) | **Cache API** عبر Service Worker | `d-notepad-v4` |

**ماذا عن قواعد البيانات لاحقاً؟** ممكن بعدة مستويات:
1. **مكتبة مستندات متعددة** داخل IndexedDB (قائمة عنوان + محتوى)، مع بحث محلي — أسهل خطوة تالية.
2. **SQLite في المتصفح** (wa-sqlite / SQL.js) لو أردت استعلامات SQL حقيقية وملف قاعدة بيانات قابل للتصدير.
3. **قاعدة بيانات سحابية** (Cloudflare D1 أو KV + مصادقة) لو أردت مزامنة بين الأجهزة — تتطلب خادماً/حساباً وتغيّر طبيعة التطبيق من «محلي فقط» إلى «حساب ومزامنة».

## النشر على Cloudflare Pages

المشروع منشور مسبقاً على Cloudflare Pages باسم **`d-a7a`** (الرابط المؤقت: <https://d-a7a.pages.dev/>)، ومربوط بمستودع GitHub **`Gamingmonster2/D`**؛ أي `git push` إلى `main` يُنشر تلقائياً.

**ربط دومين `do.com.ly`:**

1. Cloudflare Dashboard → **Workers & Pages** → المشروع **`d-a7a`** → **Custom domains**.
2. **Set up a custom domain** → أدخل `do.com.ly` ثم (اختيارياً) `www.do.com.ly`.
3. الدومين `do.com.ly` **مضاف بالفعل إلى Cloudflare** (لا حاجة لتغيير Nameservers)؛ سيضيف Cloudflare سجلات CNAME تلقائياً نحو المشروع ويصدر شهادة SSL مجاناً.
4. انتظر حالة الدومين = **Active** (دقائق)، ثم اختبر <https://do.com.ly/>.
5. (اختياري) توحيد الاتجاه: Cloudflare → **Rules → Redirect Rules**: `www.do.com.ly/*` → `https://do.com.ly/$1` (301).
6. **تنبيهات:** لا تحذف سجلات البريد (MX/TXT/SPF/DKIM) إن وُجدت، والموقع القديم (PDF) بدومينه السابق يبقى كما هو دون تغيير.

> ملف `_headers` يضيف سياسات أمان (CSP، nosniff، referrer-policy…) عبر Cloudflare Pages. وملفا `robots.txt` و`sitemap.xml` يشيران إلى `https://do.com.ly/`.

## حدود معروفة

- ترموزات ANSI القديمة الأخرى (مثل Windows-1251) غير معروضة في القائمة حالياً؛ المدعوم 1256/1252.
- الحفظ إلى ملف حقيقي يتطلب متصفحاً يدعم File System Access API (Chrome/Edge)؛ وغير ذلك يعمل بالتنزيل/الرفع.
- لا اختصارات لوحة مفاتيح عالمية (قيد المتصفح).

## من أين جاء التصميم؟

تم تحليل `C:\Windows\System32\notepad.exe` (الإصدار 10.0.19041.4522) بأدوات REA + Ghidra:
- **794 دالة، 498 دالة مفككة**، 28 مكتبة + 6 Delay-Load (comdlg32 للحوارات).
- وظائف الفتح/الحفظ (CreateFile/ReadFile/WriteFile)، كشف الترميز (IsTextUnicode + MultiByteToWideChar)، البحث/الاستبدال (FindTextW/ReplaceTextW)، إعدادات السجل (HKCU\Software\Microsoft\Notepad)، وحفظ جلسة Autosave.
- مقارنة Win32 ↔ Web في خطة التحويل: `<مسار التقرير المحلي>` (غير منشور).
